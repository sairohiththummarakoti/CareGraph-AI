# CareGraph AI — requirements and architecture starter pack

This package is a **specification**, not a working implementation. Open the included Word document for the requirements and seven flow diagrams. Use `CODEX_BUILD_PROMPT.md` with Codex to implement the actual Python project.

- `CareGraph_AI_Requirements.docx`: ready-to-review requirements and illustrated flows.
- `CareGraph_AI_Requirements.md`: machine-readable specification for Codex.
- `CODEX_BUILD_PROMPT.md`: copy-paste instruction for Codex.
- `requirements.txt`: proposed Python packages for implementation (not yet installed/tested).
- `.env.example`: tracing disabled by default.
- `diagrams/*.png`: ready-to-view flowcharts.
- `diagrams/*.svg`: editable scalable diagrams, suitable for many vector drawing tools.
- `diagrams/*.gv`: Graphviz sources. Import SVG into Visio or redraw/rebuild from these sources.

**No real patient data or authentic NCCN content is included.**
